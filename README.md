# Car Price Prediction using Machine Learning

This project predicts car prices (MSRP) using machine learning techniques
based on various car features such as engine specs, fuel type, transmission,
vehicle size, and mileage.

## Dataset
- Source: Provided dataset (11,914 rows, 16 columns)
- Target Variable: MSRP

## Project Workflow
1. Data Loading and Exploration
2. Handling Missing Values
3. Feature Engineering
4. One-Hot Encoding for Categorical Features
5. Train-Test Split
6. Model Training and Evaluation

## Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook
